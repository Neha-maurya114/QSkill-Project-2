# QSkill Project 2 – Matrix Operations Tool

A simple **Matrix Operations Tool** built using **Python and NumPy** as part of my **QSkill Python Development Internship**.

## 📌 Project Overview

This project is a command-line based application that allows users to perform different matrix operations by entering matrix dimensions and values.

## ✨ Features

* Matrix Addition
* Matrix Subtraction
* Matrix Multiplication
* Matrix Transpose
* Matrix Determinant
* User-friendly menu
* Basic input validation
* Error handling for invalid matrix dimensions

## 🛠️ Technologies Used

* **Python**
* **NumPy**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Neha-maurya114/QSkill-Project-2.git
```

### 2. Open the project folder

```bash
cd QSkill_Project_2_Matrix_Operations
```

### 3. Install NumPy

```bash
pip install numpy
```

Or install all dependencies using:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the following command:

```bash
python matrix_operations.py
```

The program will display a menu:

```text
========================================
       MATRIX OPERATIONS TOOL
========================================
1. Matrix Addition
2. Matrix Subtraction
3. Matrix Multiplication
4. Matrix Transpose
5. Matrix Determinant
6. Exit
========================================
Enter your choice (1-6):


Enter the number corresponding to the operation you want to perform.

## 🧮 Example

### Matrix Addition

Matrix A:

text
10 20
30 40


Matrix B:

text
1 2
3 4


Output:

text
[[11. 22.]
 [33. 44.]]


### Matrix Subtraction

Output:

```text
[[ 9. 18.]
 [27. 36.]]
```
